EMS Frontend - Professional CSS Update

What was updated:
- Professional responsive dashboard UI
- Sidebar + navbar styling
- Login/Register/Forgot/Reset Password styling
- Dashboard cards
- Employees, Departments, Attendance, Leave, Payroll
- Reports, Profile, My Team
- AI Home, Performance, Attrition, Resume Screening, HR Chatbot
- 404 / 403 pages
- Responsive layouts for tablet/mobile
- Central global design system and reusable buttons/forms/tables/modals
- Removed the old "Attendance Insights" AI menu/route. Attendance remains the normal Attendance module.

Installation:
1. Replace your existing src folder with the src folder in this package, or copy the provided files.
2. In the project folder run:
   npm install
3. Start:
   npm run dev

No backend/API/service logic was intentionally changed. CSS classes/wrappers were added only where needed for styling.
